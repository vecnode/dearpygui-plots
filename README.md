
# DearPyGUI plots and helpers

A set of scripts with customised graphs and plots in DearPyGUI.

### Reproduce

```sh
uv sync
```

Run an example module (opens a GUI; `timeline_multiaxis` loads `timekeys.txt` at the repo root):

```sh
uv run -m examples.bar_series
uv run -m examples.shape_editor
uv run -m examples.custom_series_tooltip
uv run -m examples.large_polygon_custom_series
uv run -m examples.stem_scatter_theme
uv run -m examples.drag_lines_points
uv run -m examples.timeline_multiaxis
uv run -m examples.screenshot
```

List all examples and the same commands:

```sh
uv run -m examples.index
```
